Publications

Accepted papers first, then preprints and submissions. My name is in bold. Color marks the area: data systems ML and LLM systems

  1. Unifying stacking and cascading for efficient ensemble inference

    Ashwin Colaco, Sharad Mehrotra, Michael De Lucia, Kevin Hamlen, Murat Kantarcioglu, Latifur Khan, Ananthram Swami, Bhavani Thuraisingham, Unnat Jain

    International Conference on Machine Learning (ICML), 2026

    Run models one at a time and stop when a learned meta-model is confident. An MDP chooses the model orderings. Up to 38x faster than the full ensemble while keeping 97% or more of its accuracy.

    project pageICMLcode

  2. Model cascades with provable per-class quality (NOMAD)

    Ashwin Colaco, Sharad Mehrotra, Michael J. De Lucia, Kevin Hamlen, Murat Kantarcioglu, Latifur Khan, Ananthram Swami, Bhavani Thuraisingham, Unnat Jain

    Conference on Neural Information Processing Systems (NeurIPS), 2026

    Cascades usually control quality in aggregate, which lets a model fail quietly on rare classes. NOMAD exits on the predicted class, certifies that a whole chain of models preserves per-class quality, and picks the cheapest viable chain with a provable 4-approximation. Up to 40x faster across 16 datasets, with zero per-class violations. With UT Dallas and the Army Research Laboratory.

    NeurIPSearlier version (arXiv)

  3. GenIE: simulator-driven iterative data exploration for scientific discovery

    Ashwin Colaco, Martin Boissier, Sriram Rao, Shubharoop Ghosh, Sharad Mehrotra, Tilmann Rabl

    IEEE International Conference on Data Engineering (ICDE), 2026, Data Engineering Future Technologies track

    Brings physics simulators inside the database with semantic filters and context-aware cost models. Exploration drops from days to minutes, with 35% lower query latency and 2.5x throughput.

    arXivICDE

  4. SALUS: automated auditing of NL-to-SQL benchmarks through weak supervision of multi-agent output

    Shiyuan Zhou, Ashwin Colaco, Sainyam Galhotra, Sharad Mehrotra

    ACM SIGMOD, 2027

    Finds annotation errors in NL-to-SQL benchmarks, which otherwise distort reported accuracy and the ranking of systems.

    arXivDOI

  5. OCTOPUS: towards a tag model for cross-query reuse in semantic query processing

    GuangXue Zhang, Nada Lahjouji, Yiming Lin, Ashwin Colaco, Sharad Mehrotra

    Preprint, 2026

    Semantic query systems discard what the model judged once a query ends. A tag model keeps those judgments so later queries can reuse them.

    arXiv

  6. What to keep, what to forget: a rate-distortion view of memory compaction in LLMs and agents

    Ashwin Colaco, Nada Lahjouji

    Preprint, 2026

    Cache eviction, quantization, prompt compression and agent summaries all trade bytes kept against answers lost. This frames them as one problem and compares them on the same budget.

    arXivCOMPACT-Bench

    Nada Lahjouji, Ashwin Colaco

    Preprint, 2026

    A survey of how agents that query databases, call APIs and keep memory across sessions put sensitive data at risk, organized around the data they touch.
