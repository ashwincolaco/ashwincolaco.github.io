# Ashwin Gerard Colaco: personal site

Static site (no build step): `index.html`, `style.css`, `script.js`.

Preview locally: `python3 -m http.server 8000` in this folder, then open http://localhost:8000.

Deploy: push to a repo named `<github-username>.github.io` (or any repo with Pages enabled on the `main` branch, root folder).
